02 · Fundamentación

¿Por qué estudiar la continuidad?

Una función continua representa un cambio sin interrupciones en un punto. En un modelo ambiental, esto ayuda a determinar si una variable cambia gradualmente o presenta una alteración.

01 · Definición

La función está definida

Debe existir un valor de la función en el punto.

f(a) existe
02 · Límite

El límite existe

Los límites laterales deben coincidir.

lim x→a⁻ f(x) = lim x→a⁺ f(x)
03 · Igualdad

El límite coincide con el valor

El valor al que se acerca la función debe ser el valor en el punto.

lim x→a f(x) = f(a)
03 · Tipos de discontinuidad

Cuando el modelo presenta una interrupción

Selecciona cada tipo para ver una explicación y su interpretación ambiental.

Discontinuidad removible

Existe un valor que falta o no coincide con la tendencia, pero el comportamiento alrededor del punto permite estimarlo.

f(x) = (x² − 4)/(x − 2) = x + 2, para x ≠ 2

Situación ambiental: una estación de monitoreo presenta una medición faltante. Los datos cercanos permiten aproximar el valor ausente sin cambiar la tendencia general.

Discontinuidad de salto

Los límites laterales existen, pero tienen valores diferentes; la gráfica presenta un salto.

lim x→a⁻ f(x) ≠ lim x→a⁺ f(x)

Ejemplo interpretativo: un indicador puede cambiar bruscamente entre dos periodos o condiciones. Es una ilustración conceptual, no una medición real de Bucaramanga.

Discontinuidad infinita

La función crece o decrece sin límite al acercarse a un punto; puede aparecer una asíntota vertical.

lim x→a⁻ f(x) = +∞ · lim x→a⁺ f(x) = −∞

En el modelo de alcantarillado de este trabajo, x = 5 representa un umbral crítico matemático.

04 · Función 1 · Racional

Análisis finito: puntos críticos e indeterminación

Se modela la carga de un sistema de alcantarillado durante una lluvia intensa. Aquí, x representa la intensidad de lluvia en decenas de mm/h y f(x) el índice de carga relativa de la red.

f(x) = (x² − 9) / ((x − 3)(5 − x))

Dominio físico indicado en el trabajo: 0 ≤ x < 5.

  1. Identificar dónde se indefine

    El denominador vale cero cuando (x − 3)(5 − x) = 0, por lo tanto x = 3 o x = 5.

  2. Clasificar las formas

    En x = 3, numerador y denominador son cero: forma 0/0. En x = 5, el numerador vale 16 y el denominador cero: forma k/0.

  3. Factorizar y simplificar
    x² − 9 = (x − 3)(x + 3)
    f(x) = (x + 3)/(5 − x), x ≠ 3, 5
  4. Calcular el límite en x = 3
    lim x→3 f(x) = (3 + 3)/(5 − 3) = 6/2 = 3

    Como f(3) no existe pero el límite sí, la discontinuidad es removible. Se puede reparar definiendo f(3) = 3.

  5. Analizar x = 5
    lim x→5⁻ f(x) = +∞
    lim x→5⁺ f(x) = −∞

    El límite es infinito y hay una asíntota vertical en x = 5.

Interpretación ambiental
En x = 3 (30 mm/h), una lectura faltante podría estimarse con los valores vecinos. Al acercarse a x = 5 (50 mm/h), el modelo señala un umbral crítico asociado a una posible saturación.

Esquema conceptual para mostrar el hueco y la asíntota. La rama a la derecha de x = 5 solo ilustra el comportamiento matemático; el dominio físico del modelo es 0 ≤ x < 5.

05 · Función 2 · Exponencial

Análisis asintótico: tendencia a largo plazo

El modelo representa una temperatura media proyectada. t indica los años transcurridos desde 2026, con t ≥ 0.

T(t) = 26 − 2,5 · e^(−0,05t)
  1. Valor inicial
    T(0) = 26 − 2,5 · e⁰ = 23,5 °C
  2. Límite al infinito

    Cuando t → ∞, e^(−0,05t) → 0.

    lim t→∞ T(t) = 26 − 2,5 · 0 = 26
  3. Asíntotas

    Asíntota horizontal: y = 26. No tiene asíntota vertical. En el modelo se considera t ≥ 0.

Lectura de alerta
Que la curva se estabilice no significa que el problema desaparezca. El modelo proyecta una temperatura media que se acerca a 26 °C; es un escenario matemático, no una predicción oficial.

Gráfica esquemática: la temperatura se acerca a 26 °C sin alcanzar esa asíntota en el modelo.

06 · Resultados

Conclusiones e interpretación ambiental

Los límites permiten interpretar datos faltantes, reconocer umbrales críticos y describir tendencias a largo plazo.

① Lo removible se estimaEn x = 3 el límite vale 3. Un dato faltante no rompe la tendencia y puede reconstruirse matemáticamente a partir de los valores cercanos.
② Lo infinito es una alarmaLa asíntota vertical x = 5 marca un umbral crítico del modelo de alcantarillado. Conocerlo ayuda a pensar en prevención.
③ Lo asintótico da una tendenciaEl límite de 26 °C indica hacia dónde se acerca la temperatura en el modelo exponencial planteado.
